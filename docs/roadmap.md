# PhageMatch roadmap and delivery status

The [project roadmap](../ROADMAP.md) describes the product direction. This page tracks the status of structural follow-up and delivery.

| Area | Current status |
| --- | --- |
| Assay provenance | The local inventory records the source workbooks, QC issues, and unresolved IDs. Assay interpretation remains under review. |
| Evaluation | The CPU-only audit uses synthetic fixtures to test split integrity, confidence intervals, and metrics. A validated real-data shortlist is pending. |
| Structural follow-up | The archived bulk folding workflow has been retired. The standalone parser has a synthetic format check. Manual interpretation is contingent on a validated shortlist. |
| Prospective validation | Pending a validated shortlist, a frozen evaluation definition, and agreement from a partner lab. |
| Active learning and prediction delivery | Pending a validated model and agreed criteria for interpreting scores and abstentions. The current delivery interface is the mocked Decision Bundle. |

Structural follow-up stays optional and outside the default evaluation work. The current milestone is lightweight software verification and assay provenance. See the [Decision Bundle interface](api_documentation.md) and [project status](../STATUS.md).
